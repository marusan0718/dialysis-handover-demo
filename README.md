# 透析室申し送りデモ

朝会で透析患者の申し送りを見やすく表示し、過去治療歴を全件全文で振り返るための静的Webアプリ試作版です。

## 注意

- このアプリはサンプルデータのみで動作するデモです。
- 実患者情報や個人情報は入力しないでください。
- データはブラウザの `localStorage` に保存されます。サーバーへの送信はありません。

## 動作確認

手軽に確認する場合は `index.html` をブラウザで直接開いてください。

ローカルサーバーで確認する場合は、このフォルダで次のコマンドを実行します。

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開きます。

### 確認ポイント

1. 朝会モードで朝会日と月・水・金 / 火・木・土クールを切り替え、選択クールの前回透析日の申し送りが表示されることを確認する。
2. 「一覧表示」「新規」「ラスト」「スキップ」の絞り込みを確認する。
3. 入力モードで対象日を確認し、姓は必須、名は任意で申し送りを保存できることを確認する。
4. 同姓同名の患者候補がある場合に、既存患者または新規患者を選んでから保存できることを確認する。
5. 入力中に選択患者の過去記録が表示されることを確認する。
6. 入力モードの一覧が対象日で絞り込まれ、前日・翌日、月・水・金クール、火・木・土クール、全履歴へ切り替えられることを確認する。
7. 朝会カードまたは入力モードの申し送り一覧から「編集」を押し、対象日が勝手に変わらず登録済み内容を更新できることを確認する。
8. 申し送り本文の一部を選択し、色ボタンで選択範囲だけ色が変わることを確認する。
9. 患者履歴モードで患者名、タグ、重要度を検索し、全文履歴を確認する。
10. 設定・データ管理で透析種別、区分、重要度、タグを編集し、入力モードへ反映されることを確認する。
11. 設定・データ管理でJSONエクスポート、インポート、サンプル初期化、全削除を確認する。

## ファイル構成

```text
index.html   画面構造
style.css    表示スタイル
script.js    サンプルデータ、画面描画、localStorage保存、JSON入出力
README.md    動作確認方法
```

## 公開

サーバー処理やビルド処理はありません。このフォルダをそのままGitHub Pages、Netlifyなどに配置できます。

GitHub Pagesでは、リポジトリの Pages 設定で公開ブランチとルートディレクトリを指定してください。

## データ構造

Electron版などへの移行を考慮し、保存データは `patients`、`records`、入力候補を管理する `settings` に分離しています。

```json
{
  "schemaVersion": 4,
  "updatedAt": "ISO 8601 datetime",
  "settings": {},
  "patients": [],
  "records": [
    {
      "recordDate": "YYYY-MM-DD",
      "recordedAt": "ISO 8601 datetime",
      "updatedAt": "ISO 8601 datetime"
    }
  ]
}
```
