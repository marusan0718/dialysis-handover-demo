# 透析室申し送りデモ

朝会で透析患者の申し送りを見やすく表示し、過去治療歴を全件全文で振り返るための静的Webアプリ試作版です。

## 注意

- このアプリはサンプルデータのみで動作するデモです。
- 実患者情報や個人情報は入力しないでください。
- データはブラウザの `localStorage` に保存されます。サーバーへの送信はありません。

## 動作確認

手軽に確認する場合は `index.html` をブラウザで直接開いてください。

ローカルサーバーで確認する場合は、このフォルダで次のコマンドを実行します。

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開きます。

### 確認ポイント

1. 朝会モードで昨日分と今日追加した申し送りが表示され、患者を「前へ」「次へ」で切り替えられることを確認する。
2. 「一覧表示」「新規」「ラスト」「スキップ」の絞り込みを確認する。
3. 入力モードで姓と名を分けて入力し、既存患者または新規患者の申し送りを保存する。
4. 申し送り本文の一部を選択し、色ボタンで選択範囲だけ色が変わることを確認する。
5. 患者履歴モードで患者名、タグ、重要度を検索し、全文履歴を確認する。
6. 設定・データ管理で透析種別、区分、重要度、タグを編集し、入力モードへ反映されることを確認する。
7. 設定・データ管理でJSONエクスポート、インポート、サンプル初期化、全削除を確認する。

## ファイル構成

```text
index.html   画面構造
style.css    表示スタイル
script.js    サンプルデータ、画面描画、localStorage保存、JSON入出力
README.md    動作確認方法
```

## 公開

サーバー処理やビルド処理はありません。このフォルダをそのままGitHub Pages、Netlifyなどに配置できます。

GitHub Pagesでは、リポジトリの Pages 設定で公開ブランチとルートディレクトリを指定してください。

## データ構造

Electron版などへの移行を考慮し、保存データは `patients`、`records`、入力候補を管理する `settings` に分離しています。

```json
{
  "schemaVersion": 3,
  "updatedAt": "ISO 8601 datetime",
  "settings": {},
  "patients": [],
  "records": []
}
```
